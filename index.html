Some websites use security headers (like X-Frame-Options or Content-Security-Policy) that prevent them from being embedded in iframes. This is a browser-level security restriction and is not something we can bypass. Most modern public websites preview just fine.

No. We do not store, log, or transmit your URLs to any server. The preview loads directly in your browser via an iframe. Your session data is stored temporarily in sessionStorage and is cleared when you close the tab.

Yes — since the preview runs entirely in your browser, you can load localhost URLs or internal network addresses (e.g., http://192.168.1.x). This makes it great for testing local development builds across device viewports.

The device frames simulate standard breakpoints: Mobile uses a 375 × 667px viewport (iPhone SE), Tablet uses 768 × 1024px (iPad), and Desktop uses a full-width view. The website inside the iframe responds to these dimensions exactly as it would on a real device.
