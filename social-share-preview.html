💡 About Universal Social Sharing

Every major social platform — from Facebook and Twitter to Discord and WhatsApp — reads OpenGraph meta tags to generate link preview cards. While each platform has subtle differences in how it renders cards (image ratios, text truncation, layout), they all share the same core set of OG tags. This means optimizing a single set of meta tags benefits every platform your content gets shared on.

This tool lets you validate all platforms in one shot, so you can spot issues before they reach your audience. A missing image means a boring text-only link on every platform. A title that's too long gets cut off differently by each platform — see all truncations at once here.

Universal best practices:

  • Title: 55–65 characters — works well on all platforms without truncation
  • Description: 120–155 characters — enough context without being cut off
  • Image: 1200×630px JPEG or PNG — the universal safe ratio for all platforms
  • Image file size: Under 5MB — some platforms (Twitter) enforce this limit strictly
  • Always include og:url — prevents platforms from canonicalizing the wrong URL
  • Use absolute URLs for images — relative URLs are not supported by any platform's crawlers
  • After deploying, clear platform caches using each platform's debugging tool (Facebook Debugger, Twitter Card Validator, LinkedIn Post Inspector)
